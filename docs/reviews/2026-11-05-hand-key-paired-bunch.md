# 手键成对串组去重

个人岗位与手键组训共用 MessageComparisonService。旧 BunchDetector 仅按当前位置上下10组判断单端串组，未关联互换的两端；位置错移时可能一端判串组、另一端判错码。

现在按当前对齐位置检查同页两组互换，配对状态放在每次比较的 ComparisonContext 中。配对检测先于多/少组判定，建立一对时增加一次 bunchGroup；另一端继续保留其报文与时长，但不再增加串组或错码扣分。单组拍成别处内容但不存在反向互换，不认作成对串组。独立错码仍正常扣分，总错误组数可以是2而串组事件数为1。

扣分依据新增可空 partnerReferenceGroup，明确另一端报底组号；两端均显示定位依据，仅一端有串组扣分，另一端提示不重复扣分。只在当前页配对，不跨翻页符调整报文。前端共用 HandKeyDeductionDetails.vue 消费新增字段，既有详情/取页端点、信封及参数不变。

验证：先运行47项相关后端测试通过；补充漏组后配对、依据中两端关联后，35项专项测试通过。覆盖相邻、同页不同距离、上下行位置互换、独立错码、单端抄错及前置漏组后的对齐。3项前端模板测试及ESLint通过。未执行依赖数据库的完整结算联调。历史已结算结果不自动重算。
