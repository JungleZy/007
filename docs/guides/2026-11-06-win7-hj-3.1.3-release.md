# Win7 HJ 3.1.3：集成已确认有效的串口修复

用户在应用HJ 3.1.2串口补丁后反馈“可行”，并要求生成完整Win7安装包。本轮将修复合入完整应用目录，版本升级为3.1.3，重新构建前端、Electron应用和compat2安装器。

## 交付行为

- HJ界面，Electron22.3.27 ia32，沿用3.1.2已验证的Java21 x86、MySQL5.7.44和对应后端运行资产。
- Windows串口从SERIALCOMM读取，查询限时8秒；全部COM口去重、按编号排序。按用户选定的COM号连接；旧选择失效或多个USB设备并存时，不自动猜选其他设备。
- Win7默认ANGLE/SwiftShader，已包含此前WebGL修复。
- 离线携带官方CH340/CH341驱动4.0.2026.02。交互安装结束后打开厂商安装窗口，允许管理员权限并点击INSTALL；开始菜单保留CH340 Driver入口。静默安装及备用ZIP需单独启动驱动安装。
- 新实例管理员为 `admin / 123456a`；升级保留已有密码与业务数据。
- 保留compat2无System/UAC/StdUtils/nsDialogs插件的安装流程。

## 构建与验证

本轮应用/前端版本及锁文件版本均为3.1.3。按 `npm run build-e-win7-32 -- --dir` 重建应用目录，再执行 `node scripts/build-win7-compatible-installer.cjs`。封装脚本新增关键源码一致性检查：最终归档内入口、图形、初始化和串口模块必须与工作区源码逐字节一致，否则拒绝封装旧应用目录。

本轮已通过16项受影响桌面测试（串口枚举与选择、WebGL配置、初始化、依赖和安装器）。应用目录构建、111份生产依赖清单、包内Electron依赖加载及NeDB持久化探测通过；compat2封装和备用ZIP完整性检查通过。后端运行资产未发生代码变更，沿用3.1.2构建结果；本轮没有执行后端Docker全量测试。

## 安装说明

关闭旧软件及报错窗口，运行3.1.3完整安装包，安装到原目录即可。无需再叠加3.1.2的WebGL或串口补丁。首次安装CH340驱动后拔插设备，在软件中选择设备管理器里CH340对应的COM号。其他COM口可以共存，无需卸载。

此前3.1.2串口补丁的现场成功反馈是本轮修复依据；新完整包的本机构建/安装测试不能外推为所有Win7版本及串口设备均已验收。
