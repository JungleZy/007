**优化建议**：
```java
// 将大方法拆分为多个小方法
private void countScore(PostTelegramTrainEntity entity, PostTelegramTrainFinishDto dto) {
    Map<String, Integer> deductMap = new HashMap<>();
    int baseScore = calculateBaseScore(entity);
    deductMap.putAll(calculateErrorDeduction(dto));
    deductMap.putAll(calculateSpeedBonus(entity, dto));
    deductMap.putAll(calculateAccuracyScore(entity, dto));
    entity.setScore(calculateFinalScore(baseScore, deductMap));
}
```
