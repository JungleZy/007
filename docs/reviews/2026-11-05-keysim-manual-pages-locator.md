# 手键手动页界与波形定位

本次用户明确要求取消手键自动翻页。正文满100组、默认尾部、旧tail=turn参数都不再自动增加翻页符；只有正文中的中文「。」或英文「.」生成完整三截翻页符。有后续正文时自动发开始符，末尾句号不额外发开始符。初始开始符仍由preamble选择。个人岗位手键复制报底恢复纯正文，句号由用户在编辑器中输入。

预览接口新增characters字段，来自生成时间轴，含字符、组号、是否控制符、起止毫秒和点划值。控制台增加按报文内容/全段组号搜索定位，重复内容可切换上一个、下一个；选中组后显示字符按钮，点击单字可定位并高亮其波形，显示点划与时间范围。原始帧有故障注入时仍按实际marks绘制，字符索引表示生成文本的计划范围。修改预览参数后清理旧定位，过期预览响应不覆盖新结果。

验证：Rust手键分页/改错及电子键回归共14项通过，13种模拟器帧与个人岗位成字处理对照通过。新增脚本keysim/scripts/check-wave-locator.mjs在独立Chrome标签页运行：101组无句号为0次翻页；手动一个句号为1次；定位7025及两个重复项切换、组号101定位、点击第二字0、未命中及旧预览拦截均通过。定位到约201.455秒，滚动位置约200960px，非仅检查按钮存在。没有发送报文或修改用户现有编辑器。

模拟器release已重新编译启动，旧控制台需刷新后加载新UI；刷新前保留尚未保存的报文。未进行真实设备拍发验收。电子键原有分页规则未在本轮改动，以上手动句号规则针对本次讨论的手键模式。
